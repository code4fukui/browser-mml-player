# Browser MML Player

Web Audio APIを利用してブラウザ上で動作する、シンプルなMusic Macro Language (MML) プレイヤーです。

![MMLコードが入力された大きなテキストエリアと、再生/停止ボタンが表示されているデモページのスクリーンショット。](https://user-images.githubusercontent.com/164197/188283422-90176884-6997-4059-994c-2831518f972b.png)

## デモ

- **[ライブデモ](https://t-sin.github.io/browser-mml-player/)**: 編集可能なMMLコードでプレイヤーを試すことができます。
- **[クリスマスデモ](https://code4fukui.github.io/browser-mml-player/player.html)**: あらかじめMMLが読み込まれた演奏デモです。

## 機能

- **ブラウザ上での再生**: Web Audio APIを使用して、ブラウザ上で直接MMLを解析・再生します。
- **マルチトラック対応**: `---` で区切ることで、複数のトラックを同時に再生する楽曲を作成できます。
- **サウンド制御**: 各トラックのパラメータを個別に調整できます。
  - `@volume`: トラックの音量を制御します（例: `@volume=0.5`）。
  - `@pan`: ステレオパンを制御します（-1.0で左、1.0で右）。
  - `@pitch`: Hz単位で周波数のオフセットを適用します。
- **テンポ制御**: `@sys.bpm` を使用して全体のテンポ（BPM）を設定します。
- **シンプルな波形**: `OscillatorNode` の矩形波（square wave）を使用して音を生成します。

## MML構文

本プレイヤーはシンプルなMML構文をサポートしています。トークンはスペースまたは改行で区切られます。

| コマンド | 構文 | 説明 | 例 |
| :--- | :--- | :--- | :--- |
| **音符** | `[cdefgab][0-9][+-]?:[0-9]+` | 音を鳴らします。形式は `(音名)(オクターブ)(シャープ/フラット):(長さ)` です。 | `c4:4`, `f+5:8` |
| **休符** | `r:[0-9]+` | 無音の期間です。 | `r:4` |
| **タイ** | `=:[0-9]+` | 前の音符を新しい長さ分だけ延長します。 | `c4:4 =:8` |
| **トラックセパレータ** | `---` | 異なるトラックのMMLを区切ります。 | `c4:4 --- e4:4` |
| **パラメータ** | `@name=value` | 現在のトラックのパラメータを設定します。 | `@volume=0.3` |

## ローカルでの開発

ローカルマシンでプレイヤーを実行する手順は以下の通りです。

1.  **前提条件**: [Node.js](https://nodejs.org/) と npm がインストールされている必要があります。

2.  **クローンとインストール**:
    ```sh
    git clone https://github.com/t-sin/browser-mml-player
    cd browser-mml-player
    npm install
    ```

3.  **開発サーバーの起動**:
    ```sh
    npm start
    ```

4.  ブラウザを開き、`http://localhost:1234` にアクセスします。
